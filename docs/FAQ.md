# FAQ

## 为什么默认是“离线示例引擎”？

首次启动时还没有安装 PyTorch/Diffusers，也没有下载模型。示例引擎让完整工作流（生成、保存、分析、评分、学习）立即可用，并明确标注“非扩散模型”。安装本地运行时后切换即可。

## 安装包有多大？为什么本地引擎还要再下载？

安装包包含 Electron、界面、嵌入式 Python 与轻量后端依赖（约 100–150 MB）。PyTorch 的 CUDA wheel 有数 GB，模型权重也有数 GB；把它们全部塞进安装包会让每次升级都变成数 GB 下载。因此本地引擎按需安装到同一个嵌入式 Python，只下载一次。

## 我的显卡已经被别的 AI 占了 10 GB，还能用吗？

可以，但要降低预期：

- 选 **SD-Turbo 512**，开启低显存守护。
- 批量 1，不要上 SDXL 1024。
- 顺序 CPU 卸载会把峰值压到约 1–2 GB，但速度会慢。
- 如果只剩 1 GB 以下，建议先关掉其他 AI，或走 CPU / ComfyUI / 云端。

## 为什么低显存模式这么慢？

`enable_sequential_cpu_offload` 会在每一层计算前把权重搬到 GPU、算完再搬回 CPU。它用时间换显存。正常模式把整个模型放在显存里，速度会快很多。

## 会不会自动微调模型？

不会。当前是本地偏好排序：学习步数、CFG、采样器与提示词片段，不改模型权重。这样可解释、可关闭、不会因为几张图把模型带偏。LoRA 微调在路线图中，会作为明确授权的独立功能。

## 图片会上传吗？

本地引擎、ComfyUI（局域网）都不会。只有你选择 OpenAI / Stability / 自定义云端时，提示词和参考图才会发给对应服务。应用无遥测。

## 支持中文提示词吗？

界面与元数据支持中文。多数开源扩散模型主要用英文训练，中文提示的效果不稳定。建议主体用英文，或在「模型」页配置一个支持提示词翻译的云端引擎。

## 为什么云端生成的尺寸和我选的不一样？

OpenAI / Stability 只接受固定尺寸或比例集合。应用会选最接近的规格，并在结果页标注实际尺寸。本地 Diffusers 会严格按 16px 对齐后的请求尺寸生成。

## 卸载会删除作品吗？

默认不会。卸载器移除程序文件，`%APPDATA%\Lumen Studio` 中的作品、数据库、模型缓存会保留。彻底清除需手动删除该目录。

## 为什么安装时 Windows 提示“未知发布者”？

当前构建未签名。请核对 Release 中的 SHA-256，或自行构建并签名。代码签名需要证书，维护者可在 `docs/BUILD.md` 中查看配置。

## 启动后一直停在“正在启动本地引擎”？

打开 `%APPDATA%\Lumen Studio\logs\backend.log`。常见原因：

- 嵌入式 Python 被杀毒软件隔离
- 端口被占用（应用会自动换端口）
- 安装不完整，`resources/python/python.exe` 缺失

开发模式请确认 `.venv` 已安装 `backend/requirements-dev.txt` 且 `uvicorn` 可导入。

## 能否在 macOS / Linux 上运行？

后端与界面是跨平台的，但当前安装包只配置了 Windows x64。Diffusers 在 macOS 走 MPS、Linux 走 CUDA/ROCm 需要自行调整设备选择与 electron-builder 配置。
